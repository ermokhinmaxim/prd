# Канал «Пиар со звёздочкой»

Рабочий блок Telegram-канала [@ermokhinpr](https://t.me/ermokhinpr). Здесь хранятся контекст и тексты, редактурой занимается скилл `redaktor-kanala` (копирайтер и пиарщик).

## Что где

| Путь | Что это |
|---|---|
| `KONTEKST.md` | Контекст канала: автор, позиционирование, ограничения, бэклог, календарь, голос. Главный документ, его читают перед любой правкой |
| `posty/` | Опубликованные тексты как есть. Образцы голоса для калибровки |
| `GOLOS.md` | Портрет голоса по опубликованным постам: приёмы, тики, типичные ошибки |
| `tools/tg_kanal.py` | Выгрузка любого публичного Telegram-канала в Markdown |
| `../.claude/skills/redaktor-kanala/SKILL.md` | Сам редактор: режимы, порядок проверки, формат ответа |

## Как прогонять текст

В сессии Claude Code на этом репозитории вставить текст и сказать, что с ним сделать:

- **«вычитай»** — корректура: орфография, пунктуация, ё, ёлочки, тире. Стиль не трогается.
- **«разбери»** — полный разбор: ограничения, одна мысль, личный абзац, стоп-слова, заголовок, концовка, факты, пиар-риски, дистрибуция.
- **«конва про …»** — каркас поста без готового текста.
- **«можно так написать?»** — быстрая проверка по ограничениям.
- **«опубликовал, куда разослать»** — план дистрибуции на 15 минут.
- **«что писать дальше»** — сверка бэклога с календарём.
- **«посмотри канал @…»** — чтение чужого публичного канала: референсы, инфоповоды, разбор кризиса.

Скилл можно вызвать и явно: `/redaktor-kanala разбери: <текст>`.

Готовых постов редактор не пишет. Это правило канала, а не ограничение инструмента.
