# prd: рабочие материалы

Всё, что сделано в окнах Claude, разложено по двум папкам: работа на «Плати по всему миру» и личный бренд. В колонке «Окно» указано, в какой сессии появился материал.

## `plati-po-miru/`: «Плати по всему миру»

| Папка | Что внутри | Окно |
|---|---|---|
| `idei/` | Каталог всех идей (`VSE-IDEI.md`) и топ-5 для запуска (`TOP-5.md`). Внутри: `spetsproekty/` (музей, коллекция Лебедева, Испытатель мира, пятна, конверт, стена), `arhiv/` (первый борд, ранние механики, быстрые ходы, конкурс), `fon/` (Медиалогия, питч под премии), `prezentatsii/` (все PDF) | Инфоповоды брендов для Плати |
| `digital-club-belov/` | Тезисы Павла Белова для Digital Club: рабочая версия, чистовик, docx для Google Docs | Тезисы для Павла Белова |
| `partnerstva/` | Партнёрский пакет Frank RG: что согласовано, сроки, варианты розыгрыша | Frank RJ партнёрские опции |

## `lichnyy-brend/`: Максим Ермохин

| Папка | Что внутри | Окно |
|---|---|---|
| `vystupleniya/` | Био спикера для конференций и форумов, темы выступлений | Максим Ермохин — выступления |
| `kommentarii/` | Комментарии для СМИ: биржи прогнозов | Маркетинг бирж прогнозов |
| `kanal/` | Telegram-канал «Пиар со звёздочкой»: контекст, портрет голоса, опубликованные посты, выгрузка постов | PR-блок копирайтинг |

Скилл редактора канала лежит в `.claude/skills/redaktor-kanala/`: Claude находит скиллы только там.

## Куда класть новое

- Всё по «Плати по всему миру» кладите в `plati-po-miru/`, для каждого проекта или мероприятия заводите свою подпапку.
- Выступления, комментарии и канал кладите в `lichnyy-brend/`.
- Если ни одна папка не подходит, заведите новую по теме и добавьте о ней строку в этот файл.
